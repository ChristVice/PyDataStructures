# PyDataStructures

This repository is dedicated to learning and implementing various data structures using Python. It includes a collection of common data structures along with code demonstrations and examples.

## Contents

- **Arrays**

- **Linked Lists**
  - Singly Linked
  - Doubly Linked
- **Stacks**
- **Queues**
- **Trees**
  - Binary Search
  - Tree
  - Trie  
- **Graphs**

## Getting Started

### Prerequisites

- Python 3.x


## Usage
- Explore the files for each data structure to find:
- Detailed explanations
- Example implementations
- Run the Python scripts to see the data structures in action.


### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ChristVice/PyDataStructures.git
   cd PyDataStructures
   ```
